# Rodokmen Jaroslava Polívky

Veřejná pracovní verze: 35 osob, 6 generací (nejstarší neúplná), 11 archivních dokladů.

Web: https://honzakud.github.io/rodokmen-polivka-web/

Údaje jsou citované z matrik; vazbu výchozí osoby na rodiče sdělila rodina. Přepisy jsou pracovní a jejich neúplnost je označena. U Jaroslava je zveřejněno pouze jméno a rok narození.

Výzkum a web připravil AI asistent pomocí šablony Jindřicha Šaršona (sarsonj/rodokmen-skill, MIT). Repozitář obsahuje pouze sestavený web, soukromé poznámky nejsou součástí.

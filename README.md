# Rodokmen Jaroslava Polívky

Veřejná pracovní verze: 15 osob ve 4 generacích a 5 archivních dokladů. Web: https://honzakud.github.io/rodokmen-polivka-web/

U Jaroslava je uvedeno jen jméno a rok narození; vazbu na rodiče sdělila rodina. Další údaje jsou citované z matrik. Přepisy jsou pracovní a místy neúplné. Vlastní zápisy starších předků zbývají k dohledání.

Výzkum a web připravil AI asistent pomocí šablony Jindřicha Šaršona (sarsonj/rodokmen-skill, MIT). Veřejný repozitář obsahuje pouze sestavený web; soukromé pracovní poznámky nejsou součástí.
